# 聚焦交互与原药混合器第一部分实施记录

实施日期：2026年9月26日。

后续更正：本记录中原有的嵌套碰撞跟随验收不足，未覆盖整段动画中的实际物理同步。用户反馈后已复现并修复子取放体的物理同步问题，详见[聚焦碰撞跟随修复记录](聚焦碰撞跟随修复记录.md)。原日志作为历史证据保留；碰撞跟随结论以修复后的物理服务器采样及真实查询为准。

依据：[实现计划](聚焦交互与原药混合器实现计划p1.md)。本记录描述实际改动和实际运行结果，不修改原计划的历史状态。

## 一、实施结果

已实现普通左键进入设备聚焦、玩家原相机0.2秒往返、聚焦期间角色冻结与手持持续跟随、滚轮切格、鼠标指针内部射线、右键退出、菜单和全局暂停协调、依赖失效恢复。四槽独立正放和倒放原有0.2秒动画，完全打开时支持指定槽位与当前道具格之间的原药转移。退出后保留槽位开闭和占用。

沿用计划暂定规则：每槽一件，不交换或覆盖；含药允许关闭；取放仅在完全打开且无事务进行时允许；进入和退出期间忽略内部左键；进入中右键从当前姿态返回；退出中重复右键不重新计时。这些规则没有被标记为新增用户答复。

本期没有增加液罐、复位、混合加工、剂量、消耗、存读档或跨场景持久化。

## 七、失败记录、修正及已知边界

1. 最初玩家检查仅证据子目录不存在导致保存失败；行为断言已通过。创建目录后27项全部通过。保留[初次结果](聚焦交互与原药混合器p1实施证据/checks/player.json)与最终结果。
2. 首次聚焦图形发现释放参考相机后，将已释放对象传给强类型辅助参数触发错误。有效性辅助入口改为先验证实例与节点类型；原失效用例最终通过。保留[首轮错误日志](聚焦交互与原药混合器p1实施证据/checks/focus-rendered.stderr.log)。
3. 首次相机时间断言把补间开始前静止帧计入运动时间。以逐帧位置确定运动起点，保持0.2秒要求，保存原始采样和计时推导，没有扩大允许误差。
4. 补充倒放夹具最初从动画零点反向启动，进入前已停止，导致恢复断言失败。[完整诊断](聚焦交互与原药混合器p1实施证据/checks/animation-full-probe.stdout.log)记录进入前速度为0；[独立恢复探针](聚焦交互与原药混合器p1实施证据/checks/animation-resume-probe.stdout.log)证明正倒放恢复方法正常。夹具改为从末端开始后定位到中点，并增加进入前确实播放的断言；恢复断言保持不变，最终通过。
5. 正常业务使用排队释放；候选入树期间排队释放设备、锚点或候选，以及立即释放不处于入树传播链上的参考相机，均通过回滚验证。另以独立故障进程刻意在入树信号中立即释放候选或整机：候选事务正确失败且保留来源，但引擎报告空视口错误；整机触发引擎关于信号发射时释放对象的错误并崩溃，退出码为−1073741819。这两项诊断不能计为通过，不保证此类引擎不安全释放方式。[候选诊断](聚焦交互与原药混合器p1实施证据/checks/immediate-candidate.json)、[整机诊断](聚焦交互与原药混合器p1实施证据/checks/immediate-device.stderr.log)。正式玩法没有加入该操作。
