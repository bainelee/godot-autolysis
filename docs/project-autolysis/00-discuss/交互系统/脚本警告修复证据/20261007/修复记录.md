# 三项脚本警告修复记录

日期：2026年10月7日。引擎版本：Godot（戈多引擎）4.6.1。用户报告三个警告，实际对应两个源码位置。

## 已确认原因与修改

1. [听筒面板焦点清理](/D:/autolysis/main-autolysis/ui/autolysis_handset_pose_debug.gd:344)原局部变量 owner（所有者）与 Node（节点）的继承属性重名，触发 SHADOWED_VARIABLE_BASE_CLASS（局部变量遮蔽基类属性）。改为 focus_owner（焦点所有者），三处引用同步更新。焦点获取、面板祖先检查及释放流程保留。
2. [打印设备事件记录](/D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_quest_machine.gd:633)原第634行有两个三元表达式，分别在 Vector3（三维向量）和 null（空值）之间取值，因此产生两次 INCOMPATIBLE_TERNARY（三元分支类型不兼容）。改为两个 Variant（变体）局部变量和显式条件赋值；有效节点记录实际位置，失效节点继续记录空值。事件字段及存活检查保留。

本次直接依据编译器报告和精确复现定位，未扩展为多原因推测。修改仅涉及局部命名与事件数据取值；原事件记录的两种值域保留。源码差异见[生产修改](生产修改.diff)，已验证来源的实际摘要见[来源摘要](修复后来源摘要.json)。
