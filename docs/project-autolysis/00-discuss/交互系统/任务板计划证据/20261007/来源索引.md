层值32对照仅在探针内存实例中修改，聚焦掩码35仍命中三槽，普通掩码3忽略三槽；不排除板根时中槽中心命中板根、左右中心无命中。该测量保留了板面当前覆盖范围。两阶段的命中差异用于核对场景结构，专项取放测试在实现阶段执行。
