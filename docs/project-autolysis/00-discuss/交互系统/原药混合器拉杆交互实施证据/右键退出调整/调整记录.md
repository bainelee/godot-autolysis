# 拉杆拖动期间右键退出调整

记录日期：2026年10月2日。依据本轮用户调整：拉动拉杆时右键退出聚焦无效，并清理对应的非必要防御代码。

## 当前行为

[右键入口](D:/autolysis/main-autolysis/player/components/autolysis_interaction_controller.gd:211)在实际拖动绑定有效时消费右键并返回，不改变聚焦会话、拉杆位置、绑定或移动／释放队列。左键释放已经处理并解绑后、最低保持及自动回弹期间，右键恢复普通退出。真实拖动尚未建立时沿用普通退出。

普通退出直接调用现有[聚焦退出流程](D:/autolysis/main-autolysis/player/components/autolysis_focus_controller.gd:88)，由同步状态通知统一清理绑定与队列。参考原项目的[右键退出入口](D:/cogito/main-degauss/prefabs/box/scripts/degauss_lockable_focus_object.gd:173)，保留直接退出及消费输入的组织方式。

## 已清理代码

- 删除右键专用排队事件、队列分发分支、右键捕获清零及退出前重复取消。实际拖动期间只增加一个明确状态分支。
- 删除每次拖动的输入累积保存字段、保存／恢复方法及调用，只保留聚焦生命周期的一套管理。
- 删除重复的活动拖动条件及重复的聚焦目标有效性检查；原目标解析方法已执行有效性检查。
- 删除双精度纵向位置缓存及顶部位置容差修补，以物理体的实际三维位置为唯一来源。底部完成与顶部归位采用同类型端点的精确比较。

菜单、暂停、窗口失焦、依赖释放、会话失效及程序指针定位补偿是原需求中仍有效的中断与输入处理，保留对应代码。本轮没有增加新的退出计时器、等待状态或输入锁。

## 端点与验收修正依据

本轮实际读取正式场景的比例为0.0009999999999999998，约为0.001，已保留。首次验收暴露原位置缓存与实际向量精度不同造成的底部完成遗漏。[Vector3（三维向量）官方说明](https://docs.godotengine.org/en/4.6/classes/class_vector3.html)明确默认分量为32位，float（浮点数）为64位。当前[拖动计算](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_handle.gd:113)写入位置后直接比较实际底部向量，不添加提前完成容差。

每秒120次物理迭代的旧测试在位置0.11999998986721、状态仍为回弹时，以近似顶部提前结束等待，导致下一次开始被正确拒绝。已将[等待归位及终点断言](D:/autolysis/main-autolysis/player/tests/blend_handle_drag_test.gd:337)统一为实际待机且位置精确等于顶部。时间与内部速度检查保留，未放宽业务许可。首次底部失败及旧等待条件失败日志均保留在本目录。
