# 任务文件打印实现计划第一部分

编制日期：2026年10月7日。状态：实现计划，尚未实施。

依据[任务文件打印讨论第一部分](/D:/autolysis/docs/project-autolysis/00-discuss/交互系统/任务文件打印讨论p1.md)、当前工程代码与场景、用户指定的原项目及 Godot（游戏引擎）4.6官方资料编制。目标是为“通知中心”接入单份任务事件、机械打印、三维纸面逐行显示和聚焦取纸，并将完成文件转移至现有携带栏。

本次交付实现计划。下文新增模块、接口、资源名称及补充默认行为均为拟定设计；英文后的中文括注用于文档解释，不写入实际文件名、节点名或接口名。首份任务的字符串标识仍需在实施配置前确定。

## 一 需求基线与实施范围

| 项目 | 必须实现的行为 |
| --- | --- |
| 通知入口 | I（任务通知测试键）触发待打印任务事件；事件只建立待打印状态，玩家仍需在通知中心聚焦中点击打印按钮。 |
| 首行 | 横轴0.2秒移至局部位置（0，-0.10，0），等待0.5秒；首次非空行开始前，打印头0.2秒移至（-0.07，0，0）。 |
| 非空行 | 打印头5秒移至（0.27，0，0）；该动作自然完成时一次显示整行，随后才执行回程。 |
| 普通回程 | 当前机械行不是本次末行时，非空行打印后0.4秒返回最左位置；空行不执行横向打印或普通回程。 |
| 换行 | 横轴0.2秒下降0.02；首行-0.10、最低-0.50，首尾均包含，共21个机械行位置。 |
| 数据行定义 | 按任务数据换行计数；空行占据机械行位置。页面自动折行和分组留白不增加机械行数。 |
| 提前收尾 | 少于21行时，在实际末行后收尾，不继续下降至最低位置。 |
| 统一收尾 | 打印头先用0.2秒返回（0.10，0，0），横轴随后用1秒返回（0，0，0）；末行为空也执行这一顺序。 |
| 完成时点 | 两根打印杆全部自然复位后才完成；同步显示第22行及以后内容，并开放聚焦取纸。打印及复位中不能取纸。 |
| 页面 | 物理页面宽0.36、高0.48；基础字号24，单页显示区域外截断。暂定画布720×960、四边留白36像素。 |
| 待打印提示 | 第一盏灯橙色闪烁，循环通知音；开始打印时恢复基础红色并停止通知音。 |
| 完成待取提示 | 第二盏灯蓝色闪烁，循环扫描音；实际取纸成功后停止，恢复基础红色。 |
| 闪烁 | 自发光倍率在0至2.0之间线性往返，每个单向过程0.5秒，完整周期1秒。 |
| 获取 | 仅在对应通知中心聚焦中取走本次完成纸张；进入现有携带栏。完成但未取走时禁止再次打印。 |

本阶段不实现多任务队列、提示衔接、一次点击打印多份文件、携带栏阅读界面、分页、滚动、自动缩小字号、任务完成判定或药物提交业务。委托中要求提交委托单的文字只作为本轮打印内容。存读档也不在本阶段范围内。

## 四 数据行与机械打印时序

### 任务数据与首份委托

任务标识使用 String（字符串），与物品类型标识及委托编号分别保存。拟以有序字符串行数组为运行快照；每个元素严格对应原文的一个换行数据行。若从多行文本导入，先统一换行符，再保留中间和末尾空行；不调用去空白处理，不依据控件折行结果拆机械行。零元素数据拒绝受理；含空字符串的数据行按空行处理，全空行测试也必须能够收尾。纯空格或制表符行的语义尚未由讨论指定，本计划拟按非空数据行处理，保留原字符，不擅自修剪成空行。

初始内容逐字保留如下，共13行。委托编号保留前导零。分组标记只增加页面留白，不往下列数据中插入空行。

```
日期：1944年9月12日
接收方：海尔塔14号地下研究所
委托方：赫铎伦北部战地医疗指挥中心
接收人：马蒂亚斯·韦尔克兰特
委托编号：07003141
委托类型：基础委托
要求：
咖啡因针剂（基础）
委托方简报：
这是你的第一份委托，你应当查阅你的手册。
你需要注意咖啡因的配置原料，最终封装为针剂。
封装后通过气动传输管道提交药物。
别忘了把委托单一同提交。
```

任务定义受理时复制成逐件快照。测试期间修改共享任务定义不能改变已开始打印的内容。完成取走后仍保存全部原始数据行，不能只保存纸面裁剪后可见的部分。不同任务标识和文本组合使用同一接口，无需为每份任务复制设备脚本。

### 行位置及动作顺序

机械处理行数＝数据行数与21中的较小值。第几行纵向位置＝-0.10－（行号－1）×0.02，行号从1开始。使用整数行索引计算目标，不用逐次浮点累减或位置比较决定是否达到容量。

1. 接受打印后，第一盏灯恢复红色、停止通知音；在锚点下建立唯一空白纸张，所有数据行初始隐藏，获取入口保持关闭。
2. 横轴0.2秒到首行，随后完整等待0.5秒。这两步不因首行为空而省略。
3. 处理本行。非空且尚未执行首次移左时，打印头0.2秒到最左；随后5秒横向打印。对应动作自然完成后先显示本行，再处理回程。
4. 本行非空且不是本次末个机械行时，0.4秒回最左。若本行为空，只保留其排版位置，不播放横向动作；未首次移左时继续保留打印头初态。
5. 有下一机械行时，横轴0.2秒下降至按索引计算的目标，再处理该行。前几行为空不增加容量，首次移左只在首次非空行前执行一次。
6. 本次末个机械行处理后，直接执行0.2秒打印头归中，随后1秒横轴复位。末行非空时不先做0.4秒普通回左；末行为空时也不省略归中。
7. 两个收尾动作自然完成且当前序号、纸张及数据仍匹配时，补全第22行及后续内容，提交完成态和聚焦获取许可，再启动第二盏灯与扫描音。

若末尾包含空行，最后一个非空行仍可能属于普通行，需先0.4秒回最左，继续处理剩余空行位置，最后才统一归中。不得将“最后一个非空行”误当成“最后一个数据行”。

### 动作实现与完成边界

打印杆使用绑定本设备的 Tween（补间动画）执行显式局部位置与时长配置，采用线性插值，横向、下降与收尾顺序执行。首位置、行距、最低位置、各时长、打印头三处横向目标均作为显式配置，默认值来自讨论；它们决定本次表现，不作为纸张能否进入携带栏的额外阈值。

每个有限阶段以本次 Tween.finished（补间自然完成信号）推进；销毁补间、外部停止和暂停不能当作完成。回调携带打印序号与阶段身份；终止后旧回调不显示行、不推进归位、不影响下一份文件。独立循环闪烁不接入打印完成链。测试总耗时和位置误差只用于对应配置的验证，不用于提前解锁。

当前打印杆是网格节点，沿其局部轴移动，保留场景父级变换。实施记录每段开始、自然完成、行显示和收尾完成的顺序。若以后改成带运动物理体的结构，先测完整变换应用与物理同步读取点，再决定完成待同步阶段；不能用固定等待帧数替代实际探针。

### 数值核算与验收对照

容量计算：（-0.10－（-0.50））÷0.02＋1＝21。第20行-0.48，第21行-0.50，第22行-0.52，故第22行不再驱动机械下降。首份13行的末行位置为-0.34。

理论时长按配置动作相加：首降0.2＋等待0.5＋首次移左0.2（存在非空行时计入）＋5×机械范围内非空行数＋0.4×普通回左次数＋0.2×后续下降次数＋归中0.2＋复位1.0。普通回左次数等于机械范围内非空行数，减去“末个机械行非空”时的1；后续下降次数为机械行数减1。

## 五 三维纸面与提示表现

### 纸面布局

在任务纸张下新增 SubViewport（子视口）与二维纸面界面，通过 ViewportTexture（视口纹理）显示于独立正面网格。正面尺寸0.36×0.48，与现有纸张平面一致；深度偏移依据实际正面方向和渲染结果确定，避免共面闪烁，不把偏移值设为业务门禁。文字朝向、纹理纵向方向和正反面显示必须在获准的图形检查中核实。

画布720×960，文字区域648×888，四边36像素对应物理留白0.018。正文左对齐、深色、字号24；数据行分别使用可自动换行的文字控件，保留原始行索引。使用显式支持中文的字体或实际可用回退字体，测量真实文字宽度和行高，不以字符数代替排版结果。

初始建立完整排版但隐藏行文字；隐藏只改变绘制，不移除布局占位。每个非空数据行的横向打印结束时一次显示整行，自动折成多条视觉行也同时显示。空行保持对应留白。完成时显示全部剩余数据，超出文字区域的部分由裁剪容器截断，禁止自动增加页面或滚动条。

暂定单数据行基础高度预算40像素，“要求”前与“委托方简报”前各16像素。实际自动折行增加对应数据行高度，后续行随完整布局定位。13×40＋2×16＝552像素，小于888像素可用高度；该预算不能替代真实字体测量。纸面视口必须在新增行显示时更新，不能设置为始终不更新；最终画面刷新与机械完成事实分别记录。

### 提示灯与音效

第一盏灯使用 mat_glow_orange_0.tres（橙色发光材质零号），第二盏灯使用 mat_glow_blue_0.tres（蓝色发光材质零号），结束对应提示时使用 mat_base_red_3.tres（基础红色材质三号）。对需要动画的发光材质创建本机独立副本，每盏灯独立控制，不能改写共享资源。参考[现有材质复制](/D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_machine.gd:99)和[线性闪烁](/D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_machine.gd:175)。

新增位于设备位置的 AudioStreamPlayer3D（三维音频播放器），分别播放 sfx_machine_notice_0.wav（待打印任务提示音零号）和 sfx_machine_scanning_0.wav（文件待取扫描提示音零号），使用现有 SFX（音效总线）。音量和空间衰减列为可配置表现参数，实际试听后核实，不编造用户未指定的音量。

循环参考[电话音流配置](/D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_telephone_audio_controller.gd:179)：复制 AudioStreamWAV（波形音频流），按实际采样数据配置完整循环端点与正向循环。读取采样长度只用于循环端点，不决定任务、打印或获取许可。停止提示必须停止对应音源并失效旧循环；不靠未配置循环的导入资源自动循环。

灯、音源及按钮按压缺失时记录并停止对应表现，打印与取纸仍依据必要业务事实。按压动作可以与打印开始并行，不等待按压自然结束。初始化、恢复或归位只恢复配置属性，不重放按钮动画中的方法、音频或其他事件轨道。

## 六 聚焦登记与取纸事务

### 通知中心接入

在主体上配置 FOCUS（聚焦模式）交互组件及直属聚焦描述器，绑定现有聚焦相机。打印按钮和动态纸张配置 DIRECT（直接模式）组件，但可用性查询与执行入口均强制校验玩家正聚焦本设备；这里的直接模式用于既有聚焦内部点击机制，不开放退出聚焦后的普通获取。

在聚焦描述器增加通知中心专用登记分支：登记主体、相机、按钮及当前纸张。动态创建纸张后登记，成功取走或清理前解除匹配登记。无纸张的空闲与待打印阶段仍是合法聚焦目标；未完成纸张可以被识别但拒绝获取。旧纸张释放回调必须匹配打印序号，不能移除后来纸张的登记。

射线查询只返回当前通知中心显式登记的按钮或当前纸张首命中，不穿透外部物体，不全局枚举同名节点，不沿任意父级推断归属。主体按现有聚焦查询机制排除。碰撞层与遮挡依据现有查询掩码配置，并验证主场景相机实际能命中按钮和纸张；扩大碰撞或新增穿透规则须有实际命中证据。

### 携带栏提交顺序

新增专用接口，沿现有设备取出事务复用当前格、聚焦会话、逐件身份、普通持物互斥和展示准备机制。既有封装取出流程只能作为模式参考，不能向其设备类型判断中塞入不匹配对象。

1. 查询和正式入口同时检查：玩家输入有效、聚焦对应通知中心、纸张为本次完成实例、设备无获取事务、当前格为空、携带栏依赖有效且普通持物许可成立。
2. 保存玩家、聚焦会话、选格、持物修订、设备、打印序号、纸张和逐件资源身份；同时取得携带栏与设备获取互斥。查询阶段不消费来源。
3. 准备纯展示模型。准备失败时释放候选与本次锁，纸张留在锚点，待取提示继续；不清除完成态。
4. 准备后的所有可调用边界再次核对同一上下文。切格、退出聚焦、纸张释放、来源替换、玩家失效或持筒状态变化均拒绝旧请求，不转移后来会话的物品。
5. 必要准备全部成功后进入同步双方提交阶段：当前格写入同一逐件资源，设备撤销本次来源占用和动态登记，提交展示并清除本次待取状态。该阶段不跨等待帧、不提前发布观察，保证最早观察者看到库存与设备事实一致。
6. 所有仍可能失败的提交操作必须放在来源释放前；无法保证时建立匹配本次身份的双方回滚。失败后恢复纸张、占用、当前格与待取状态，不能仅销毁来源。正常双方提交后的观察重入不撤销已经成功的获取。
7. 成功提交后停止蓝灯与扫描音、恢复第二盏红灯，完成世界纸张的清理，再发布持物与取走观察通知。通知边界保持互斥，并复核释放安全；来源模型清理只影响本次纸张。

取得纸张后，逐件资源的任务标识和全部原文保持不变；不自动销毁任务内容、不把委托编号转为数值、不扩展原料放置与设备装填入口。成功只发生一次。失败获取不结束扫描提示，也不允许打印第二份。

## 七 状态 暂停与异常清理

| 状态 | 进入事实 | 打印与取纸许可 |
| --- | --- | --- |
| 空闲 | 没有本次任务、纸张或事务。 | 可接收单份任务事件；不能打印或取纸。 |
| 待打印 | 请求受理并保存快照，尚无本次纸张。 | 聚焦中可点击打印；不能取纸。 |
| 打印 | 已建立本次空白纸张，顺序处理机械行。 | 拒绝重复打印和取纸；可退出聚焦。 |
| 归中与复位 | 本次末个机械行已处理，顺序收尾。 | 同样拒绝打印和取纸，不提前启动待取提示。 |
| 完成待取 | 本次两杆自然复位完成，全文已补全。 | 聚焦中按现有携带栏条件获取；禁止再打印。 |
| 获取提交 | 匹配来源与当前格进入受保护事务。 | 拒绝其他打印、获取与任务替换；失败恢复待取，成功回到空闲。 |
| 异常清理或待恢复 | 必要打印目标、纸张、数据或设备来源失效，或本次显式取消。 | 本次未完成纸张不可取；清理及必要归位完成前不接受新打印。 |

时序暂停同时识别 SceneTree.paused（场景树暂停属性）以及玩家真实菜单暂停事实。当前菜单只改移动暂停标记，[实际暂停查询](/D:/autolysis/main-autolysis/player/autolysis_player.gd:194)已把场景树、移动暂停与界面状态统一用于对话。通知中心参考同一事实接入，不把持续聚焦当作暂停。打印动作、首行等待、灯闪烁与提示音保存原进度，恢复后继续；暂停期间拒绝操作，不消耗数据行或重复显示。

设备保留可以处理来源清理的所有者，时序放入可暂停子树并处理真实菜单暂停。不要直接继承玩家的始终处理模式而让补间继续。必要依赖失效与可选表现失效分开：打印杆或本次纸张丢失终止打印；灯、按压或音源丢失只停对应表现；相机或核心聚焦登记失效结束相应聚焦操作，不发布虚假打印完成。

显式取消立即失效本次序号，停止有限动作与对应提示，撤销未完成纸张的获取和登记。来源仍有效时，保留取消原因并按当前配置执行受控归中、复位，清理未完成纸张；这是取消恢复，不显示剩余文本、不通知正常完成、不重复创建纸张或提交库存。必要目标无法归位时记录待恢复，由有效引用重新绑定并恢复初态后才允许新请求，不静默自动重试。

开始阶段预检或纸张创建失败时不消耗待打印快照，回到待打印并按实际可用表现恢复提示。已成功开始后显式取消结束本次任务，不自动再次排入待打印。已完成纸张被外部释放属于来源异常，清理匹配待取状态并记录丢失原因，不冒充玩家成功取走。
