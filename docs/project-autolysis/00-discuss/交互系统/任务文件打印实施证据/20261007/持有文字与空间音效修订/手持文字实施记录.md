# 手持任务文件文字修订实施记录

本记录只覆盖本代理负责的手持文字与相机投影修订。设备空间声音由机械代理负责。修订前完整来源快照由根代理保存在本目录的“实施前”，本代理未修改库存控制器、通知中心生产脚本、主场景或工程配置。

## 正式失败反馈与实际归因

使用 diagnosing-bugs（故障诊断）技能。最小反馈调用真实玩家场景的 try_receive_instance（接收逐件资源），经过现有库存准备、提交和 watch_instance（监听逐件资源）链，再递归读取当前手持展示中的已显示 Label（文字控件）。未直接替换显示节点或库存结果。

“正式失败反馈/正式手持白纸失败反馈.json”记录退出码1：逐件全文保存、正式接收两个断言通过；实际文字为零行，唯一失败为“正式手持展示可见本件全部自然行而不是白纸”。“来源定位”继续记录接收后原资源身份与十三行原文均保留，四项断言中的三项通过、同一文字断言失败。该轮实际执行的测试来源已保存为“来源定位/已执行测试.gd”。反馈命令及参数均保存在每次检查的结构化执行记录。

先列出并区分三个候选原因：显示适配缺失、接收时数据丢失、已有文字仍隐藏。实际原模型只有 BoxMesh（盒网格）及底纸材质，子树没有文字控件；正式接收后的资源身份和全文正确，排除了后两个原因。修订后同一原始反馈从零行变为十三行全部已显示。

首个“失败反馈”夹具曾替换玩家脚本，导致导出的 item_drop_shapecast（丢弃物品形状查询）引用丢失、初始化提前失败。该轮保留为夹具失败历史，不用于证明白纸原因。随后使用未替换脚本的真实玩家场景，才取得上述正式失败。

纯展示场景新增无脚本的 PaperViewport（纸面视口）和 PaperFront（纸面正面）。AutolysisQuestPaperVisual（任务纸张展示适配）由手持呈现器调用，只在源模型通过既有纯展示校验后，组装明确引用的可信纸面视图。场景资源本身仍没有脚本、碰撞或交互组；候选中的外部脚本不会提前执行。

每个模型独立拥有子视口、覆盖材质、视口纹理和全文排版。完整文本从同一逐件资源读取并复制，适配不查询世界纸张或设备。准备好的候选在正式提交后直接显示；后续逐件通知比较任务标识、全部自然行和分组标记。内容等值时复用现有视图，实际变化时只替换排版，继续使用本模型原视口、材质和纹理。空内容会清除旧文字；切格与玩家释放继续由模型子树销毁和既有监听解绑完成清理。

## 聚焦投影第二个实际缺口

通知中心源相机 fov（视角）实际为55度，普通玩家为75度。初次独立量测证明普通视角十三行均在1280×720画面内，但这不能证明完成聚焦后取纸仍完整可见。

“聚焦几何补验”初次未满足无图形驱动中的原生捕获指针要求，正式进入、相机过渡和退出均失败。该轮后续投影断言没有证明聚焦表现。本代理修正夹具，仅沿既有库存专项替换入口输入许可为玩家真实基本许可且未聚焦；仍执行正式 try_enter（进入聚焦）、必要目标检查和自然相机过渡，入口失败立即停止量测，不直接赋值聚焦状态。

“聚焦几何入口修正”实际进入55度相机后，45项断言中的44项通过，唯一失败为聚焦全文区域超出画面。第12个自然行的最大横坐标约1297.005、最大纵坐标约787.9427，真实超出1280×720边界。

最小生产修订复用现有听筒的相机投影补偿：当前模型绑定任务文件时也按开始跟随时保存的投影矩阵与当前投影矩阵比例调整手持显示；普通模型正式提交时同步一次跟随。这保护的是取纸后立即看完整原文的表现，不读取几何结果作为业务许可，也不改物品六轴配置、打印完成条件或库存事务。

## 最终专项实测

最终来源冻结：手持呈现器304行、纸面适配100行、纯纸张模型34行、手持专项333行。准确散列与原项目参考散列见“手持文字来源散列.json”；四项执行来源副本位于“手持冻结来源”。冻结后只写本记录及证据，不再编辑生产或专项。

“手持最终专项/手持全文正式取纸与投影.json”记录退出码0，59项断言全部通过。标准错误日志0字节；对标准输出和标准错误同时检查脚本错误、引擎错误、警告、退出对象泄漏、资源残留及渲染资源分配残留，均无命中，见“手持全文严格汇总.json”。重复轮次不累计为更多断言。

专项包括：真实库存接收的原始白纸反馈；同一逐件资源身份和独立全文副本；正面材质与当前视口纹理身份；源场景纯展示校验；20次重复监听与等值通知不重建排版；并列候选的材质、视口和纹理隔离；两件文件分格反复切换；未选中另一件更新不串字；当前内容更新保留空行、空格、制表符和末尾空行；等值内容副本不重排；清空与恢复内容；旧排版释放；玩家释放后全部监听断开。

初轮专项把所有资源观察者总数误断为必须1，41项中两项失败。实际真实玩家还包含现有内容界面观察者，最终证据记录全部观察者2、其中手持呈现器1。修正的是特定呈现器监听计数的检查，并未删除既有观察者或把数量作为业务许可。

最终新增真实取纸链：空手进入通知中心、通过显式短动作配置加快几何专项、等待正式有限动作自然完成十三行打印、调用 try_take_quest_paper（获取任务纸张）、确认世界来源实际释放、读取同一逐件资源的手持全文。未替代设备完成事件或获取事务。正式聚焦中的空格切换、文件切回和正式退出也经过实际入口。
