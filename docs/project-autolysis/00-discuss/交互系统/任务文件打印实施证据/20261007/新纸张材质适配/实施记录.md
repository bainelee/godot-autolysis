# 新纸张材质适配记录

日期：2026年10月7日。执行依据为用户更换任务纸张材质后重新适配的要求。引擎实际版本为 Godot（戈多引擎）4.6.1。

## 实际来源与适配

用户更换后的[正面材质](D:/autolysis/main-autolysis/assets/materials/paper/mat_paper_test_0.tres:4)及[纸体材质](D:/autolysis/main-autolysis/assets/materials/paper/mat_paper_test_1.tres:4)均为 StandardMaterial3D（三维标准材质），底色为（0.67，0.600655，0.5159，1），启用 uv1_triplanar（第一组纹理坐标三平面映射）。适配前世界纸张把不透明文字视口直接写入新正面材质的 albedo_texture（反照率纹理）；手持展示仍使用旧内嵌浅色材质，运行时还会改写底色。该事实由适配前源码和真实引擎红回归确认。

本次将基础纸面与文字分层：世界及手持正面继续使用用户正面材质，纸体使用用户纸体材质；独立 material_overlay（材质叠加）承载文字。两个用户材质文件的实际摘要与适配前一致，未重写颜色或三平面配置。

## 官方与原项目证据

- 官方 [GeometryInstance3D（三维几何实例）叠加材质](https://docs.godotengine.org/en/4.6/classes/class_geometryinstance3d.html#class-geometryinstance3d-property-material-overlay)说明叠加材质绘制在现有活动材质之上；[Viewport（视口）透明背景](https://docs.godotengine.org/en/4.6/classes/class_viewport.html#class-viewport-property-transparent-bg)说明透明背景设置。显式界面背景仍会绘制，因此共享视图中的旧颜色矩形同时删除。
- 官方 [BaseMaterial3D（三维基础材质）](https://docs.godotengine.org/en/4.6/classes/class_basematerial3d.html)说明阿尔法透明度与三平面映射；[Resource（资源）复制](https://docs.godotengine.org/en/4.6/classes/class_resource.html#class-resource-method-duplicate)支持独立运行时资源。本次实际探针核验每模型的文字材质与视口纹理均独立。
- 原项目[声音锁显示绑定](D:/cogito/main-degauss/recorder/ui/3d_widgets/sound_lock_display.gd:50)仅在运行时复制显示材质并绑定子视口纹理，避免编辑器保存动态纹理路径；[显示材质](D:/cogito/main-degauss/recorder/ui/tape_timeline_quad_material.tres:4)采用透明、无光照、白色及禁纹理重复配置。上述来源为实际参照，未宣称上游已有本项目纸张文字分层实现。
