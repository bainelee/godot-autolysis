# 聚焦期间手持听筒不可见修正

日期：2026年10月4日。用户反馈姿态回填后取下听筒不可见，并确认仅发生在电话聚焦期间。临时界面的目的为调整取下后玩家手中模型的局部姿态；用户位置（0.33，−0.12，−0.27）和角度（16，125，12）继续保留。上一轮只复验配置传递、接口和取放，遗漏实际网格在聚焦视角下的投影检查。

复现保留正式主场景、电话、玩家及真实层级，通过根交互组件进入聚焦、通过听筒组件取下；测量实际当前玩家相机与五个网格的180个面顶点。先按六个视锥平面裁剪实际三角面，再检查非零屏幕投影面积，避免把节点可见属性或包围矩形当作画面内可见证明。模型与所有网格的场景树可见和相机图层均有效。

已证明本场景原因：原相机跟随只保存空间相对变换；聚焦切换至设备55°视场角后，同一用户手持姿态的屏幕投影扩大，全部实际网格面落在视锥外。界面关闭不修改模型姿态；工具开启时也能重复同一症状。

## 实际修正

[呈现器开始跟随](D:/autolysis/main-autolysis/player/components/autolysis_held_item_presenter.gd:17)同时保存入聚焦前相机投影。[同步入口](D:/autolysis/main-autolysis/player/components/autolysis_held_item_presenter.gd:31)仅在独占听筒持有且原、当前投影均为透视时补偿横纵投影；每次从原相机相对变换重算，不累积变换。横纵比例分别由原投影系数除以当前投影系数取得，深度轴保持为1；比例左乘完整相对变换，同时处理基底与原点，使每个实际面顶点保留普通视角的二维投影。

[取下提交](D:/autolysis/main-autolysis/player/components/autolysis_held_item_presenter.gd:151)在显示入树前同步，并继续复核对象有效性；入树失败撤销会话后恢复原跟随。[归还清理](D:/autolysis/main-autolysis/player/components/autolysis_held_item_presenter.gd:189)撤销持有序号后同步恢复。结束聚焦仍恢复入聚焦前呈现器局部变换和独立标记。普通道具和空手的会话序号为零，沿用原跟随表达式。

用户子模型六值、局部缩放、运行缓存、电话聚焦镜头55°配置、挂机模型与世界电话姿态均未修改；临时工具仍默认关闭，按键仍为空绑定。投影分母为零或比例非有限时只回退原跟随表现，不新增取放许可条件。透视模式检查用于确认本补偿公式适用，不限制业务。源文件变化与保持项见[来源核查](当前来源核查.json)。

数学依据为[官方相机投影说明](https://docs.godotengine.org/en/4.6/classes/class_camera3d.html#class-camera3d-method-get-camera-projection)、[官方投影矩阵列定义](https://docs.godotengine.org/en/4.6/classes/class_projection.html#class-projection-property-x)及[指定版本透视矩阵实现](https://raw.githubusercontent.com/godotengine/godot/4.6.1-stable/core/math/projection.cpp)。实际零相机偏移、单位相机基底的对称透视配置已通过逐顶点测量；不将本次结果扩展为任意相机偏移、缩放或非透视投影均保持画面位置的证明。
