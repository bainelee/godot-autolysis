| [显示恢复](D:/autolysis/main-autolysis/player/components/autolysis_inventory_controller.gd:408) | 显示实例异常释放先按当前缓存姿态和本次模型配置恢复；只有恢复实际失败或必要呈现器失效才异常终止。正常退出聚焦、暂停与输入关闭不清占用。 |
| [独占呈现接口](D:/autolysis/main-autolysis/player/components/autolysis_held_item_presenter.gd:113) | 只创建没有脚本、物理或交互组件的展示模型，姿态应用到子模型。来源与会话绑定控制提交、调节和清除；普通显示提交不能覆盖独占模型。原有相机跟随保持。 |

电话使用 begin_handset_take（开始取筒）与 begin_handset_return（开始归还）取得正整数事务序号，再使用 is_handset_transfer_current（复核听筒预处理）验证等待期间身份。最终 commit_handset_take（提交取筒）或 commit_handset_return（提交归还）接收无参数的来源提交、来源回滚及来源通知可调用对象。来源提交返回布尔值；失败时库存保持预处理，来源先恢复碰撞，再调用 cancel_handset_transfer（取消听筒事务）。取下会话序号等于其事务序号，归还使用新的事务序号并保留原持有会话身份。

玩家调用 get_handset_transfer_pending（读取听筒预处理）取得短暂移动保护事实，读取 get_holding_revision（读取持物变更序号）复核点击请求。held_item_changed（持物变化通知）与 inventory_changed（库存变化通知）独立：电话取放不伪造四格内容变化。普通库存的实际内容或选格提交也增加持物变更序号。

面板读取 get_handset_session_snapshot（读取听筒会话快照），其字段为 source（来源）、display（显示实例）、serial（会话序号）、initial_position（取下初始位置）与 initial_rotation_degrees（取下初始角度）。应用姿态使用 apply_handset_pose（应用听筒姿态），身份复核使用 is_handset_display_session（验证听筒显示会话）。显示恢复后发布持物变化通知以重新绑定面板，持有会话身份保持。

## 保留检查的实际用途

| 检查 | 保护的业务事实及实际来源 |
| --- | --- |
| 四格索引及当前实例 | 取筒要求当前选中格为空，但允许其他格存物；等待后复核同一索引及持物变更序号。来源为本工程库存实际四格实现与电话计划。 |
| 来源、玩家、事务与持有序号 | 禁止另一电话、另一玩家、旧取消和旧异常回调清新会话。正整数表示有效会话，零表示没有会话，不表示业务计时。 |
| 聚焦稳定态及聚焦会话身份 | 普通模式不能直接取筒；异步预处理后必须仍为同一稳定聚焦。只读查询不创建模型或写碰撞。 |
| 必要呈现器、纯展示场景可实例化 | 保证听筒可以形成手持表现，并隔离脚本、碰撞及交互行为。检查场景描述后再准备模型；不检查网格数量或装饰名称层级。 |
| 正式电话已提交来源有效 | 模型入树同步通知后，电话仍匹配玩家与会话，必要展示、限位及实际碰撞掩码仍有效。生产只调用正式电话的明确只读接口，专项夹具显式覆写该接口进行故障注入。 |
| 已完成持有标志 | 成对提交及必要来源复核全部完成，才增加持物变更序号和发布持物变化。部分占用失败只清理来源与显示；已完成会话异常终止仍发布必要清理通知。 |
| 姿态向量有限 | 位置、角度与缩放必须能形成有效变换。数值来自来源配置或当前运行缓存；零位置、负值或任意有限角度都不作为取放门禁。 |
| 通知嵌套层数 | 内层异常清理通知返回后，外层观察者仍不能嵌套执行普通库存写入。来源完成通知只在完成玩家、来源、回调接收者及持物变更序号仍有效时执行。 |
| 依赖离树与显示身份 | 来源、玩家和必要呈现器异常触发匹配清理；单纯显示实例丢失先恢复。调节面板并非库存必要依赖。 |

库存不读取动画时长、轨道数量、挂机端点姿态或限位几何阈值。位置误差比较只出现在姿态专项断言中，验证实际调节、恢复和缓存的表现值，不决定普通取放是否完成。

## 实际参考与验证

[原项目快速槽循环](D:/cogito/addons/cogito/InventoryPD/CogitoQuickSlots.gd:217)在实际循环入口依据携带状态拒绝切换；本实现采用入口保护，但锁的生命周期由原电话归还或异常终止决定。[原项目手持装备](D:/cogito/addons/cogito/Components/PlayerInteractionComponent.gd:223)采用独立手持场景与装备容器；本实现只扩展本工程呈现器，不引入上游背包和存档。[原项目摆动](D:/cogito/addons/cogito/Scripts/wieldables_sway.gd:9)由父容器负责位置摆动；本实现独立调节听筒子模型。[原项目基础交互](D:/cogito/addons/cogito/Components/Interactions/BasicInteraction.gd:14)先执行设备业务再通知观察，最终使用本工程已有唯一执行边界。

正式测试脚本为[听筒库存专项](D:/autolysis/main-autolysis/player/tests/handset_inventory_test.gd:1)。夹具使用正式玩家场景，库存派生类替换聚焦许可及已提交来源有效性，以隔离验证库存事务，并显式注入必要来源失效；呈现器派生类只在明确的恢复失败用例注入准备失败。正式电话来源的真实物理依赖由独立模型入树复核验证。38项旁路使用实际设备。最终[执行结果](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/电话聚焦交互实施证据/20261004/inventory-final-source-provider/handset-inventory-final-source-provider.json)记录引擎版本4.6.1稳定官方版、无图形参数、时间、进程编号、退出码、断言数及错误检查；[全部123条断言](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/电话聚焦交互实施证据/20261004/inventory-final-source-provider/internal/听筒库存断言.json)保存每项结果。

独立复核在正式电话的挂机可见性同步回调中调用库存异常终止，实际发现来源提交返回后继续读取已经清空的预处理姿态，以及归还异常终止后仍发布正常归还通知；[取下失败记录](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/电话聚焦交互实施证据/20261004/commit-observer-audit-first/commit-observer-audit.stderr.log)与[归还错误状态](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/电话聚焦交互实施证据/20261004/commit-observer-audit-return/提交观察回调复核.json)保留。修复后在来源回调前复制模型、姿态、持物变更序号、索引及聚焦序号，来源回调后使用[同一事务身份复核](D:/autolysis/main-autolysis/player/components/autolysis_inventory_controller.gd:362)确认仍为本次动作，再读取快照并继续成对提交。[当前来源回滚](D:/autolysis/main-autolysis/player/components/autolysis_inventory_controller.gd:356)只允许同一事务，取消或后来建立的新会话不能被旧回滚覆盖。库存新增同步取下取消、同步归还取消及取消后立即建立新会话三组验收；[正式电话提交观察复核](D:/autolysis/main-autolysis/player/tests/telephone_commit_observer_audit.gd:1)的[10条阶段检查结果](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/电话聚焦交互实施证据/20261004/commit-observer-recheck/telephone-commit-observer-recheck.json)通过，取下与归还同步取消都只发布一次异常终止，归还只增加一次持物变更序号。

显示可见性回调释放候选的测试同时检验来源回滚与呈现器独占锁清除；否则库存虽取消成功，普通模型仍会被呈现器独占标记阻断。归还显示离树观察者排队释放玩家的测试同时检验来源保持已归还、通知不补发给失效完成玩家。
