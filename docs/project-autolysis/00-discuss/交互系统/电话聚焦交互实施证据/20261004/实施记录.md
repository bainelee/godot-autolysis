## 限位同步与数值用途

限位调用 set_deferred（延后赋值）切换 disabled（是否停用），延后任务携带来源与单调修订序号；普通物理帧通过 intersect_shape（形状相交查询）核对实际物理标识和形状拥有者，再提交。没有以固定等待帧数作为生产完成许可。启停及取消恢复期间玩家保持短暂移动保护，稳定持有时解除该保护。

| 配置或读取 | 保护事实、用途与来源 |
| --- | --- |
| 听筒内部物理层32，限位层8 | 来自项目既有物理层定义。前者只供聚焦内部查询，后者进入玩家实体掩码9并排除交互射线。持有玩家必须实际包含限位掩码。 |
| 取筒安全范围 AABB（轴对齐包围盒） | 场景显式配置为起点（−0.43，−1.3，0）、尺寸（2.28，3.1，2），来自真实房间墙体及玩家着地位置。取筒前确认玩家完整活动形状在安全侧，并另查临时限位真实重叠；不用于普通动作完成许可。 |
| 玩家实体层非零 | 当前启用前的重叠查询依赖玩家可查询实体层；零层无法证明不重叠时拒绝取下。稳定持有不另加零实体层门禁。实际缺口与修复见独立复核。 |
| 原薄墙尺寸、端点及固定墙位置 | 只核对当前资产能否封闭活动区域。主场景原有北、南、西侧固定墙与临时薄墙形成封闭范围，未恢复用户已删除的附加体。 |
| 物理帧、延后写入事件与物理命中 | 证明请求写入和实际生效的区别，保存来源身份；测试等待上限仅用于使故障明确失败。 |
| 姿态有限值、来源与显示身份 | 防止无效变换及旧面板写入新会话；不按任意姿态、网格数量或装饰名称批准业务。 |
| 移动轨迹中的边界与误差 | 只测量正式资产的走、跑、蹲行、斜向、贴边及台阶表现；不进入电话提交许可。主场景玩家根原有80度旋转，定向诊断按实际变换处理。 |

必要依赖在来源提交、挂机可见性回调及手持模型入树回调后再次复核。部分占用失败只回滚，不发布成功持物通知；来源仍有效时恢复挂机和停用限位。可调用边界的旧取消与回滚不覆盖随后建立的会话。

## 失败纠正与官方依据
