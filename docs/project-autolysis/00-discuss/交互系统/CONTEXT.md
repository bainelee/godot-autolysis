# 聚焦交互术语

本文件记录已确认的领域术语。行为规则与证据见[聚焦交互与原药混合器讨论第一部分](/D:/autolysis/docs/project-autolysis/00-discuss/交互系统/聚焦交互与原药混合器讨论p1.md)。

**聚焦交互模式**：玩家进入指定设备的固定观察位置，通过鼠标指针选择设备内部交互物的操作模式。
避免混称：道具栏的聚焦道具格。

**当前聚焦设备**：本次聚焦操作所针对的设备。
避免混称：鼠标当前指向的槽位。

**聚焦交互物**：进入所属设备的聚焦交互模式后可操作的设备内部对象，例如混合槽位。

**混合槽位**：原药混合器中可打开、关闭并容纳原药的位置。本次讨论涉及编号0至3的四个槽位。
避免混称：玩家道具格、原药放置架槽位。

**原药取放交互区**：混合槽位中用于确定放入或取出原药操作的命中区域。
避免混称：用于开闭槽位的命中区域。

**原药放置锚点**：混合槽位中确定原药摆放位置的参照位置。
避免混称：原药取放交互区。

**空手状态**：玩家当前选中的道具格为空。其他道具格中有原药不改变此状态，沿用[道具系统术语](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/CONTEXT.md)。
