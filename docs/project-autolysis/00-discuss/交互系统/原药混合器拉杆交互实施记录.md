# 原药混合器拉杆交互实施记录

记录日期：2026年10月2日。依据为[原药混合器拉杆交互实现计划](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/原药混合器拉杆交互实现计划.md)。已实现拉杆业务、设备登记、顺序输入与原生指针循环。自动验收与实际程序定位分别留存证据；真人操作体验未确认，比例仍为临时参数。

本轮用户调整已覆盖原计划的右键中断提案：实际拖动期间右键无效，松开或完成后恢复正常退出。右键专用队列及重复防御清理、当前比例和最新复测详见[右键退出调整记录](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/原药混合器拉杆交互实施证据/右键退出调整/调整记录.md)。以下既有验收表保留初次实施结果，最新结果以调整记录为准。

## 已写入的拉杆业务

[autolysis_blend_handle.gd（混合器拉杆脚本）](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_handle.gd:1)新增四个状态：待机、拖动、最低保持、回弹。顶部为0.12，底部为−0.12，最低保持0.1秒，完整回弹0.2秒，返回速度为1.2局部坐标单位／秒。每次纵向事件单独限位；开始、持续、松开、取消均核对角色归属；只有拖动达到严格下限才发出一次完成通知。通知前先改变状态并清除角色归属，通知后不再访问可能已由同步回调释放的拉杆成员。

[配置校验](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_handle.gd:60)核对存活设备、设备子树归属、聚焦描述、唯一直接子交互组件、有效直接子碰撞形状、同步唯一请求接收者及有限正比例。配置失败不会启用拉杆入口。[位移接口](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_handle.gd:105)只接收绑定角色的纵向位移，不读取全局鼠标、不修改道具栏或鼠标模式。当前以物理体的实际三维位置作为唯一位置来源，底部完成和顶部归位使用同类型端点的精确比较；双精度位置缓存及顶部位置容差修补已删除。只有本脚本写拉杆物理体的局部位置，横向与深度固定为0。

[自动流程](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_handle.gd:137)运行于物理帧。控制器先处理输入，拉杆物理处理优先级为100。进入最低保持或回弹的物理帧是计时零点，不将同一帧的完整时长再次计入新状态。保持结束时剩余有效时间用于当帧回弹。场景树暂停会冻结最低保持和返回计时；角色离开已完成的拉杆不会撤销完成或阻止设备自动返回。

## 比例配置状态

mouse_to_handle_ratio（鼠标位移到拉杆位移比例）的脚本初始配置为0.0005局部坐标单位／鼠标视口纵向输入单位。本轮实际读取正式场景中已保存的值为0.0009999999999999998，约为0.001，予以保留。检查器允许修改，非法值使配置失效。目前未取得真人操作的行程与体验确认，因此不得称其为最终比例，也不得据此新增固定半屏阈值。

## 顺序输入与中断

[autolysis_interaction_controller.gd（交互控制器脚本）](D:/autolysis/main-autolysis/player/components/autolysis_interaction_controller.gd:153)将尚未解析的开始许可和持续事件分开保存。按下继续经过未处理输入与物理帧射线；移动、释放由[玩家前置输入](D:/autolysis/main-autolysis/player/autolysis_player.gd:219)观察。每个移动单独计算，不求净位移；释放在前面的移动之后处理，帧末按钮状态只作兜底。开始请求实际分发后，必须确认拉杆真的进入该角色拖动状态才建立唯一绑定。

切格只作废尚未解析的开始请求，保留已绑定持续事件。绑定后移出碰撞区域不会重新查询其他物体。已有释放排队时允许新的左键按下继续排队，由实际物理状态判断顶部可开始或回弹中拒绝；持续按住的重复按下不会产生新周期。实际拖动期间右键只被消费，不退出聚焦，不清除绑定和有序输入。真实拖动尚未建立、左键已松开并解绑、最低保持及自动回弹期间，右键使用正常退出流程；没有右键专用排队分支。

菜单、暂停、窗口失焦、取消标记、会话终止、设备／玩家／依赖释放、视口大小或坐标变换改变均清理绑定和排队状态。已完成的最低保持和回弹由拉杆自身继续；暂停只冻结自动计时。同步完成监听回调使用 queue_free（排队释放）删除设备的路径已验收。回调内 free（立即释放）信号源会触发引擎自身的信号发射期删除错误，初次对抗记录保留，不能列为无错误通过项。

## 指针循环与输入累积

[循环实现](D:/autolysis/main-autolysis/player/components/autolysis_interaction_controller.gd:404)在物理队列和原生窗口消息全部处理后，按最新真实指针位置判断上下边缘。通过 get_screen_transform（取得屏幕变换）转换到窗口客户区坐标，定位到另一边内侧并保留横向位置。完成、释放或取消后停止循环。定位前后调用 DisplayServer.process_events（显示服务器处理窗口事件）形成消息分界；定位回声只扣除记录的实际定位分量，保留同条消息的真实移动残差。后端已重建基准的零相对位移不再次扣除；无法核对旧基准时取消本次拖动并记录警告。

指定版本原生消息批处理会在按下回调执行前累积鼠标移动。因此稳定聚焦时提前保存并关闭 Input.use_accumulated_input（输入累积），确保第一批按下、下拉、上推也逐条进入控制器。当前只保留聚焦生命周期的一套保存和恢复，已删除每次拖动重复执行的字段、方法及调用。菜单、暂停、退出及节点释放恢复进入稳定聚焦前的精确原值。该行为提高稳定聚焦阶段可见鼠标事件的分发频率；未修改全局项目输入配置。[实际源码与补偿研究](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/原药混合器拉杆交互实施证据/鼠标定位补偿研究.txt)保存了版本源码索引和网址。

最初隐藏窗口探针未收到原生鼠标事件，不能作为通过证明。单项验证包装器增加 Visible（可见窗口）选项用于真实窗口输入验收，原有自动检查继续隐藏运行。修正为可见窗口后，指定引擎已记录7条实际原生移动事件：[实际事件](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/原药混合器拉杆交互实施证据/鼠标定位自动可见/实际事件.json)、[成功包装记录](D:/autolysis/docs/project-autolysis/00-discuss/交互系统/原药混合器拉杆交互实施证据/定位探针包装日志/定位探针自动可见.json)。窗口800×600、内容1600×1200，实际变换比例0.5；底边至顶边定位产生的纵向相对位移为−1184、未缩放纵向位移为−592，证明定位跳变必须补偿。首次重新建立基准时相对位移为0，证明不能无条件扣除。

新增[正式原生循环验收](D:/autolysis/main-autolysis/player/tests/blend_handle_native_loop_test.gd:1)已通过170项断言，退出码0，错误日志为空。正式玩家和正式混合器在1280×720窗口下分别使用无内容缩放和1920×1080内容缩放。测试通过输入解析注入按钮，再由测试驱动定位系统指针，移动事件由指定引擎的实际窗口后端生成；生产控制器自身的循环定位另行识别与补偿。

两种模式均覆盖两轮下边缘循环、一轮上边缘循环、同一物理帧前的下推／上推／下推、生产定位回声与松开同物理帧、固定镜头、可见指针、无错误完成、提前松开回弹。内容缩放模式另验证窗口大小改变取消绑定。实际记录包含51条输入事件，其中46条鼠标移动、37条测试驱动移动、8条生产循环回声，另含初始化移动；保存201个物理帧样本和6张画面。普通模式的生产循环纵向分量为±715，内容缩放模式为±1072.5，与记录的实际程序定位量相等，逐步拉杆位置检查未出现整屏跳变。此测试为程序驱动原生事件，不是真人体验。

实际调用定位后，原生移动消息有时要到后续主循环才到达，不能假定调用 process_events（处理窗口事件）后立即必有回声。生产控制器保留待补偿量直到对应消息到达；测试也等待实际原生消息再继续驱动。初次测试错误地假定立即派发、以及缩放模式注入按钮坐标重复变换，均保留失败证据；最终测试已按实际后端事件修正。

## 操作体验限制

computer-use（计算机操作）工具访问测试窗口时等待应用授权超时，用户回复“无授权提示”。因此没有将工具操作或程序模拟称为真人试拉通过。实际体验和最终比例须由正式运行中的操作确认；编辑器嵌入游戏窗口的实际运行也未覆盖，当前图形通过证据来自独立游戏窗口。定位回声与后续真实移动合为单条系统消息的专门图形案例未直接构造，残差算法依据指定版本源码和七组算术验证，不将其冒称该专门图形案例通过。可使用新增[拉杆集成测试](D:/autolysis/main-autolysis/player/tests/blend_handle_drag_test.gd:1)的手工模式观察比例、行程、状态、完成次数和碰撞采样，第八功能键保存画面与报告，第九功能键结束。
