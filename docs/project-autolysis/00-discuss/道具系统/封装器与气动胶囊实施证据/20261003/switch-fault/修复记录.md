# 封装器开关重复拨动故障修复记录

日期：2026年10月3日。状态：已复现、修复并完成定向回归。用户报告开关拨动两次后出现控制件运动故障，本次修复针对实际端帧判断；修改保留在工作区，未提交版本。

## 实际复现与原因

[正式玩家输入复现](D:/autolysis/main-autolysis/systems/item-system/tests/packing_switch_repeat_test.gd:7)经过实际聚焦、库存放入、有限物理射线及左键输入处理。修复前每秒30帧的两次独立执行都在第二轮零号开关开启后触发用户同一运动故障，首轮三类开关开闭成功。[首次失败进程与命令](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/switch-fault/checks/重复拨动图形30帧修复前.json)、[重复确认](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/switch-fault/checks/重复拨动图形30帧复现确认.json)及[逐次运动采样](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/switch-fault/input-before-30/重复拨动输入报告.json)保留原148行报错。

[最小控制件复现](D:/autolysis/main-autolysis/systems/item-system/tests/packing_motion_physics_test.gd:27)移除库存和鼠标流程，仅实例化正式机器并调用同一开关的公开选中方法，仍在第二轮开启后失败。图形上限15、60帧与无图形模式均复现。

故障时动画已经停止，进度为端点0.1599999964秒；实际旋转为−0.785415828227997弧度，关键帧及配置缓存目标为−0.785398185253143弧度。差值为0.0000176429748535156弧度，约0.00101度。默认向量近似比较返回假，随后写入永久运动故障并阻止继续操作。

| 待验证原因及预测 | 实际验证结果 |
| --- | --- |
| 比较容差不足：实际误差超过默认阈值，但保持微小且稳定。 | 默认比较阈值在该角度约为0.00001弧度，实测误差约0.0000176弧度，默认比较失败。改用统一0.0001弧度容差后，原失败流程通过。 |
| 物理同步尚未完成：继续等待后旋转应该自然抵达原阈值范围。 | 故障后额外等待六个物理步，实际角度及误差保持不变，不符合该预测。 |
| 重复播放改变了动画端帧：最后关键帧或配置缓存应与初始目标不同。 | 最后关键帧及配置缓存始终一致，未改变，不符合该预测。 |

等待与端帧对照见[稳定误差取证](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/switch-fault/before-endpoint-stable/连续拨动报告.json)。取证另用四元数向量和标量的反正切计算角距，避免普通四元数角距在微小角度下因单精度返回零。

## 修复内容

[运动控制脚本](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_motion.gd:9)新增0.0001弧度端帧容差，约0.00573度。[统一端帧方法](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_motion.gd:168)核对三轴环绕角度差向量的长度，拒绝非有限值。开启查询、关闭查询和运动完成检查共用该方法。

原动画轨道、速度、方向、物理同步、暂停方式及故障锁保留。实际端帧、动画停止、状态和待完成条件仍同时成立才开放后续操作；发生明显偏移时继续报错，错误信息增加预期角度、实际角度和动画进度。

修复前原始脚本保存为[修复前脚本](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/switch-fault/修复前运动控制脚本.gd.txt)，采用文本扩展名避免引擎导入时登记重复全局类。
