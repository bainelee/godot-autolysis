## 实现结果

封装器初始两槽为空。液体罐位接受空罐和满罐，胶囊位接受空胶囊和封装胶囊；占用槽不交换、不覆盖。业务操作要求稳定聚焦本机，胶囊取放额外要求舱门完全打开。两槽使用独立物理入口，槽内物品的普通拾取停用；非本机物体继续阻挡射线。

合法满罐与空胶囊允许三类互斥选择，再次点击当前类型取消。开关和舱门分别播放原场景动画，保留末帧、反向关闭和中途取物复位。稳定开门、关门均可启动，运动和取放事务期间拒绝启动。

启动记录本轮两件实例、完整源数据及类型，使用可暂停的物理游戏时间计时两秒。运行期间锁定全部业务入口和再次聚焦进入；右键退出后继续加工。完成时先同步清空罐、写入胶囊并刷新显示，再发布通知。源节点失效或字段变化时拒绝完成，保留可用来源，避免半提交或重复产物。

胶囊独立保存原药顺序及重复条目、三项相位、五项波形和封装类型。完成后先取罐保留选择；成功取走本轮产物胶囊才清除完成身份、复位开关及各灯原材质。支持取回、放回和连续批次，旧产物数据不会随来源重新装填而改变。

胶囊架可重复供应独立空实例，两个陈列胶囊保留外观并改为纯显示。空胶囊标识灰色，封装胶囊采用指定绿色发光材质引用；世界、槽内和手持显示一致。手持封装胶囊显示完整内容，空胶囊隐藏面板。废液罐合法开盖时可整件销毁空胶囊和封装胶囊。

实际实现位置及原项目参考见[参考索引](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊实施证据/20261003/参考索引.md)。

最终各组非预期错误为零。封装交付每轮故意改变来源字段，各产生一条预期故障；原子提交最终轮释放两类来源，共两条预期故障；旧无图形回归包含八条预期故障注入错误。原始错误日志保留，预期故障不作为正常运行错误隐去。
