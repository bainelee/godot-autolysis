# 道具系统术语

本文件仅记录本轮已明确的领域术语。具体需求、代码依据和待确认问题见[道具系统讨论第一部分](道具系统讨论p1.md)。

**道具栏**：正常游戏过程中常驻屏幕下方、用于携带道具并选择当前手持道具的一组道具格，无需额外按键唤出。

**道具格**：道具栏中用于容纳一个道具的独立位置，同种道具也不叠加。
避免混称：放置架槽位。

**聚焦道具格**：道具栏中当前被选中的道具格，其内容决定当前手持状态。
避免混称：交互系统的聚焦交互、准星瞄准目标。

**手持状态**：聚焦道具格中有道具时的玩家状态，对应道具显示为手持物。

**空手状态**：聚焦道具格为空时的玩家状态。其他道具格是否有道具不改变此定义。

**原药**：可以从原药组取得、存入道具栏并临时放在原药放置架上的道具。离开原药组的世界原药本身也是可交互物。

**原药组**：提供对应原药的交互点，成功取药不会使其陈列或数量减少。

**原药放置架**：通过有限槽位临时存放原药、允许再次取回的场景物体。咖啡因与苯甲酸钠可以混放，共用全部槽位。

**放置架槽位**：原药放置架中具有确定放置位置的存放位置。
避免混称：道具格。
