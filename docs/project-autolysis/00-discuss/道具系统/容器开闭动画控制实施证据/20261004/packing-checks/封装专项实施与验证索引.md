# 封装专项实施与验证索引

记录日期：2026年10月4日。范围：封装舱门、三个类型开关、开始按钮、两处库存槽位、状态灯及封装专项测试。全工程完成状态由总实施索引判定。

封装业务执行绑定已迁移到明确可调用入口。门与开关删除固定时长、单轨道、角度端帧比较及初始化资源身份合同；整机配置只保留核心对象、引用归属及加工计时依赖。开始按钮按压、类型灯、开始灯和完成灯分别隔离。两秒加工仍由业务常量启动，输入身份、来源快照、物品内容与外观成对提交及回滚保留。

封装运动采用根时序探针已验证的方案：保留物理同步，在物理处理内手动推进独立播放器，临时关闭局部变换通知，把多属性动画结果合并为一次完整变换提交。目标自然完成记录当前动作序号与资源，在下一物理处理捕获实际完整变换后发布稳定状态；稳定阶段不持续重写变换。暂停只挂起控制件的手动推进，续播继续同一次播放，不调用原生暂停或重新播放，保留进度和完整变换且不重放当前方法事件。挂起期间仍复核外部停止、名称、方向与资源接管。自然完成与暂停发生于同次推进时保留本次完成结果，续播后发布稳定态。普通取消恢复上一确实完成稳定态；类型取消由整机清除全部选中标记并恢复关闭。播放器重新绑定建立关闭态，不恢复取消的选择或业务提交。

初始化与恢复采用临时属性副本消费未推进播放残留的启动事件；只停用该副本的方法、音频及动画播放轨道，不修改原资源启用位。临时库名逐次检查是否被占用并递增避让；来源库可以使用临时库默认名称。合法请求本身的零秒方法事件可以执行；取消和恢复不得追加执行。立即方法轨道在定位和推进中释放控制件时，实例与动作序号复核阻止旧变换提交。立即方法轨道内部取消或重新绑定时，先失效序号并登记恢复请求，待引擎定位或推进返回后才停止播放器、变更引用和操作临时动画库，避免重入修改引擎正在遍历的动画缓存。真实取物触发类型反播时，也在当前原生推进返回后才启动反向动作。旧播放器不在回调内部释放，重新绑定接口负责停止与解绑；节点生命周期由明确拥有者处理。

## 保留条件与失败历史

仍保留的数值、类型和资源检查各有实际用途：两秒属于业务规则；正速度与非循环决定自然完成；手动物理处理及物理同步用于合并变换；根引用和祖先检查用于实际归属；交互组件直接隶属命中物理体用于现有射线查找；类型编号0至2对应既有封装类型；双完成灯数量只约束显示；本次动作及同步等待资源身份只用于拒绝外部替换，不属于初始化永久身份合同；临时副本轨道分类只用于避免恢复重放事件。

早期失败记录不删除，不用于有效通过计数：原子第一次执行器预期错误次数配置不符合两次来源释放实际日志，随后区分罐与胶囊故障原因并分别核对；灯第一次保留了旧聚合断言且等待混合普通帧造成跨物理帧采样，已改为入口隔离及物理帧与完成事件采样；图形完整第一次未等待新废液罐初始化稳定态，第二次已修正并通过；运动第四次测试采样读取已停止播放器当前时间，已保护；运动第六次把合法请求自身零秒事件错误计入取消，已在请求后记录事件并使用立即方法轨道核验；隔离第八、九次新增立即暂停后，零秒原生重新播放再次触发方法事件，均实际失败两项；第十次起改为仅挂起手动推进，零秒、推进与终点方法暂停均通过。临时库名冲突属于静态发现，修复后来源同名库实测保留，没有声称修复前已运行复现。

未验证：人工编辑器操作资产后重新运行、人工鼠标及原生全局鼠标自动注入。停止运行前编辑资产的有效变体由运行夹具入树前修改真实动画资源并重新初始化验证。封装专项不代替其余设备、共享模块与全工程最终导入检查。
