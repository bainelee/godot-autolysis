# 共享交互实施记录

执行日期：2026年10月4日。范围：共享交互入口、聚焦登记、六类普通道具生产接线、直接演示场景与相关验收夹具。设备动画与事务实现由对应设备记录说明。

## 实施结果

[共享交互组件](D:/autolysis/main-autolysis/components/interactions/autolysis_interaction_component.gd:23)新增 set_execution_handler（设置执行入口）、clear_execution_handler（清除执行入口）和 has_execution_handler（检查执行入口）。检查执行入口支持期望回调核对。执行绑定要求有效、在场景树内、未排队释放的节点和单参数回调；保持原来的模式、物理父级、可用性只读查询和分发互斥保护。

[请求分发](D:/autolysis/main-autolysis/components/interactions/autolysis_interaction_component.gd:87)先同步调用本次权威入口一次，再发布 interaction_requested（交互请求信号）观察通知；通知期间继续拒绝重入。返回真仍表示已分发。组件、物理来源或发起者被释放、离树或排队释放时，不再向失效上下文通知。观察订阅数量和延后通知不参与业务许可。

六类生产拥有者已改为明确执行绑定：[原药单体](D:/autolysis/main-autolysis/systems/item-system/autolysis_raw_material.gd:27)、[原药组](D:/autolysis/main-autolysis/systems/item-system/autolysis_raw_material_group.gd:12)、[原药放置架](D:/autolysis/main-autolysis/systems/item-system/autolysis_raw_material_shelf.gd:16)、[液体罐](D:/autolysis/main-autolysis/systems/item-system/autolysis_liquid_tank.gd:34)、[气动胶囊](D:/autolysis/main-autolysis/systems/item-system/autolysis_pneumatic_capsule.gd:28)和[胶囊架](D:/autolysis/main-autolysis/systems/item-system/autolysis_pneumatic_capsule_shelf.gd:12)。[演示场景拥有者](D:/autolysis/main-autolysis/player/tests/fixtures/direct_interaction_demo.gd:23)同步迁移，删除场景中的三条原业务信号接线。

[聚焦登记](D:/autolysis/main-autolysis/components/interactions/autolysis_focus_target.gd:23)检查设备祖先、明确拥有者和实际命中配对，不再汇总各控制件 is_configured（配置有效）结果。槽位、拉杆和液体罐位按登记设备祖先关系校验，槽内锚点按所属槽位祖先关系校验。物理体的直接子交互组件查找约定继续保留。设备、聚焦锚点和核心登记失效仍结束会话；单入口的运动依赖失效由该入口拒绝。

[封装运行登记复核](D:/autolysis/main-autolysis/components/interactions/autolysis_focus_target.gd:191)先以未限定类型的引用数组检查已登记对象，避免释放对象被强制写入类型数组产生引擎错误。

## 失败与纠正记录

最初两次在沙盒内启动引擎，尚无脚本断言时发生访问冲突，退出码为−1073741819；保留[首次直接检查](shared-checks/shared-direct-01.json)及[首次组件检查](shared-checks/shared-component-01.json)和对应错误日志。后续按已授权验收在沙盒外执行成功。两次启动失败不计为业务断言失败，也不计通过。

[直接检查第二次记录](shared-checks/shared-direct-02.json)保留实际夹具问题：将释放对象写入类型数组产生错误；立即释放正在执行方法的组件被引擎拒绝。夹具改为使用未限定类型引用进行剩余对象清理，组件释放采用排队方式；立即释放发起者和父级物理来源仍覆盖。对应[错误日志](shared-checks/shared-direct-02.stderr.log)保留引擎的锁定对象错误，修复后53条无图形和129条图形断言均无非预期错误。不将该夹具失败归因于设备业务。
