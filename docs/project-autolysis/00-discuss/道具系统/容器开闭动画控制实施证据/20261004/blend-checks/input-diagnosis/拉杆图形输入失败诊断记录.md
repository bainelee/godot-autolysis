# 拉杆图形输入失败诊断记录

日期：2026-10-04。结论：首段已实际复现的失败来自自动夹具的合成输入坐标与操作系统指针循环定位混用。本轮仅修改测试源，不修改生产拉杆或生产交互控制器。完整无图形拉杆复验890项通过；完整图形拉杆的原24项失败保留，未将最小段对照记为完整图形通过。

用户随后明确禁止操作鼠标与覆盖正在使用的屏幕。限制到达后立即停止图形检查，核实本代理启动的44504、11892、30064三个图形测试进程均已结束且系统查询不存在。未终止用户已有编辑器或其他程序。之后仅运行一次完整无图形复验，没有再启动图形引擎、窗口或指针检查。

## 首段实际因果

最小段接收记录全部为当前注入调用内分发，本次没有观察到额外的非注入鼠标事件；因此不将额外原生移动作为该次首段失败的必要原因。实际数据如下：

1. 第79物理帧，合成下拉事件相对纵量60，落点为(1076.587,482.2863)，拉杆按正式场景比例0.001到达0.06。根图形视口读取的系统指针却为(1112,873)。
2. 第80物理帧，循环定位参数记录原点(1076.587,482.2863)、落点(1112,4)，待定位消息为真。生产代码以系统指针定位前后差计算补偿，按实际数据可复算纵量4−873=−869。记录中的原点来自最后合成事件，补偿量来自实际操作系统指针，两者属于不同输入基准。
3. 下一合成横移事件落点(1196.587,482.2863)，相对量(120,0)。位置减相对量倒推得到(1076.587,482.2863)，恰好匹配所存原点；[生产定位补偿分支](D:/autolysis/main-autolysis/player/components/autolysis_interaction_controller.gd:185)因此将纵量0减去−869，形成869。
4. [生产有序输入应用](D:/autolysis/main-autolysis/player/components/autolysis_interaction_controller.gd:294)把该纵量交给拉杆。0.06−869×0.001低于完整行程底限，被限位到−0.12。第81帧出现完成信号，与原始首段异常相符。

观察器的接收回调在玩家处理之后，因此同一横移接收记录中的待定位标记已经为假；较早的物理上下文记录保留了为真的状态。最终测试源新增注入前后上下文，以避免仅凭处理后的标记漏掉这个区别。定位参数变化观察记录是测量到的变化次数，不冒充原生循环的通用精确次数。

末段旧基准(1076.587,104)、定位前(1076.587,542.2863)、定位后(659,4)的警告另有一致的夹具原因：合成绝对坐标夹到画面内部，但相对位移保留完整输入量，因此位置减相对量不能继续表示实际系统定位后的原点。首段异常已经由上述实际数据独立解释，无需用晚段警告替代首段证据。

机制依据已核对[官方输入解析文档](https://docs.godotengine.org/en/4.6/classes/class_input.html#class-input-method-parse-input-event)：Input.parse_input_event（输入事件解析）把事件送到游戏，但不移动操作系统指针。[4.6.1版视口源码](https://github.com/godotengine/godot/blob/4.6.1-stable/scene/main/viewport.cpp#L1339-L1355)中，具有鼠标功能的根图形视口从显示服务器读取实际指针；[窗口后端源码](https://github.com/godotengine/godot/blob/4.6.1-stable/platform/windows/display_server_windows.cpp#L886-L910)实际使用系统指针读取和定位。原生循环算法是否满足真实用户操作仍需独立验证，本次夹具失败不能作为该算法通过的依据。

## 最终改动与边界

唯一新增源代码改动为[拉杆输入测试](D:/autolysis/main-autolysis/player/tests/blend_handle_drag_test.gd:147)：

- 自动图形模式设置 root.unfocusable（根窗口不可聚焦），人工模式保持原输入路径。
- 若设置后 root.has_focus（根窗口仍有焦点）为真，记录失败并在创建正式设备及注入输入前结束该检查。不能将一个仍有焦点的窗口当作隔离成功。
- 原有完整断言和正式 Input.parse_input_event（输入事件解析）链保留；新增只读实际接收事件、注入前后上下文及循环参数观察。没有在生产代码增加测试开关，也没有过滤失败事件。
- 保留最小段参数用于重复定位同一症状；没有新增临时调试打印。完整无图形路径的原890项断言已实际通过。

最终自动图形前置门没有在限制到达后再次图形运行，完整图形拉杆仍保留原失败状态。19项首段对照发生在最终前置门加入之前，并且有焦点采样仍为真；它仅说明该次首段结果，不能证明不可聚焦设置在已存在窗口上完成了焦点撤销。真人拖动、系统鼠标循环及体验检查仍未验证。
