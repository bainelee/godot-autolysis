## 独立发现的边界与处理状态

1. 初次读取发现封装运动与配药槽仅核对动画名称、资源身份及正在播放，缺少同名反向接管检查。这可让外部同名反播在关闭端点完成后仍按原打开目标建立业务许可。当前两处已加入实际播放方向检查，新增同名反播用例已经包含于各自后续有效运行。
2. 初次读取发现两个直接容器没有本次动作资源身份与受控物理体绑定身份。已通知根执行者；最新代码已经保存本次动作资源和绑定物理体，并对更换后的配置要求显式重新绑定。此项保护仅限运行中的请求归属。
3. 完成信号到下一物理帧建立稳定态之间，外部再次播放或更换资源可能接管原结果。四类控制件当前均检查待同步窗口的实际指定目标、停止状态与本次资源；配药后续还保存结果动作序号。此检查覆盖恢复待同步，没有改为比较旧端点或时间阈值。配药不同目标播放后暂停的独立实测见后文。
4. 配药槽初次读取遍历所有启用轨道，并将任意轨道目标缺失汇总为整个槽不可用。若附加的是可选音效、显示方法或装饰轨道，这会连带限制门和已有来源取放。当前已删除该总门禁，[槽位配置](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_blend_slot.gd:65)只检查真正必要的门体、锚点及播放根依赖；附加方法目标释放不否决已有门动作和其他槽。
5. 封装运动初次读取在播放器推进后直接读写自身变换，缺少立即方法轨道释放自身后的有效性边界。当前[推进](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_motion.gd:226)与[即时定位](D:/autolysis/main-autolysis/scenes/prefabs/prefab_machines/scripts/autolysis_packing_motion.gd:269)均核对自身活性、动作序号和必要依赖，先处理推进内取消或重新绑定，再决定是否提交旧帧。配药推进返回也先恢复通知，再检查自身排队释放、候选播放器活性和必要依赖。
6. 源播放器使用命名动画库时，完整限定名称有效；配药整机和封装整机初次实现却把该限定名称直接当作新空库内的动画键。独立引擎探针实际返回错误码31，目标没有加入。当前两整机分别复制库名与库内动作键，保留运行播放器的限定名称；新增命名库和临时恢复库冲突避让回归已有实际通过证据。
7. 根执行者要求追加检查两个直接容器的立即方法取消边界。废液罐原生推进内部实际崩溃，柜门独立同输入探针通过，未测到旧帧覆盖；修复后原联合探针两类均通过。后来追加暂停与依赖失效取消又实测到废液罐崩溃，均已针对原生调用内部清缓存修正；后文分别保留各轮源、日志和修复后结果。

## 零秒事件独立实测

检查了[引擎4.6.1稳定版动画播放器源码](https://raw.githubusercontent.com/godotengine/godot/4.6.1-stable/scene/animation/animation_player.cpp)。源码停止方法没有清除播放刚开始标记；seek（定位）在执行 update_only（仅更新属性）前先处理“刚开始”的零秒普通更新。因此该参数本身不能覆盖“外部或本次播放刚开始、尚未推进就取消或重新绑定”的所有情形。

实际探针使用指定4.6.1稳定官方引擎，以手动播放器、零点二秒非循环动画、零秒方法轨道与事件计数对象运行。受限启动首先发生引擎启动崩溃；随后通过可访问引擎用户目录的进程使用隐藏窗口运行，两次有效探针退出码均为零，错误日志为空。归档的[事件探针源脚本](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/容器开闭动画控制实施证据/20261004/独立复核/probe.gd)对应普通副本再跑；[普通副本标准输出](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/容器开闭动画控制实施证据/20261004/独立复核/shallow.stdout.log)与[普通副本错误输出](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/容器开闭动画控制实施证据/20261004/独立复核/shallow.stderr.log)保存其原始结果。早先深复制运行的[标准输出](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/容器开闭动画控制实施证据/20261004/独立复核/stdout.log)和[错误输出](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/容器开闭动画控制实施证据/20261004/独立复核/stderr.log)保留；早先源脚本没有另外保存，其复制参数变化已在本节注明。

| 实际序列 | 累计方法事件计数 |
| --- | --- |
| 停止、指定动画、属性专用定位、暂停，作为初次初始化 | 0 |
| 接受播放后同帧立即执行同样的恢复序列 | 1 |
| 接受下一请求后立即推进零秒，随后同帧执行恢复序列 | 2；本请求只增加一次合法启动事件，恢复不追加。 |
