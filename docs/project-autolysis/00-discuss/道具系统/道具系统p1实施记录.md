# 道具系统第一部分实施记录

实施日期：2026年9月25日。

依据：[讨论文档](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统讨论p1.md)、[实现计划](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统实现计划p1.md)。本记录区分实际测试结果、实施前问题和仍可调整的表现参数。

## 已实现行为

道具栏随玩家初始化显示，初始四格全空、聚焦第一格，正常游戏期间持续可见；没有唤出按键、自动隐藏或淡出计时器。单格80×80像素，间距10像素，总范围350×80像素，下边缘距底端80像素。1920×1080窗口实测左上角为（785，920）；1280×720窗口为（465，560）。见[布局测量](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/layout.json)。

滚轮向下切下一格、向上切上一格，两端循环；当前格决定空手或手持。每格只有一件道具，不叠加，不自动查找其他空格。道具栏忽略鼠标、关闭界面焦点，不启用玩家的界面占用标记，不影响正常移动与直接交互。

两种原药组无限提供对应原药，组内四件陈列保持不变。组外独立原药可以直接取走。手持原药点击架体时，选择编号最小的空槽位；空手瞄准具体瓶体才能取回该件原药。两个架子分别维护36槽占用，支持两种原药混放；满架、无效资源或失效目标均不扣除玩家原药。

## 资产与场景修正

边框及聚焦音效直接复制自参考工程，复制前后校验一致；格子尺寸、间距、背景和聚焦填充使用实际参考配置。两种图标由本工程原药模型在同一相机和灯光下渲染，均为256×256透明图片。源文件、校验值及渲染参数见[资产来源记录](/D:/autolysis/main-autolysis/assets/ui/inventory/资产来源.md)。

手持局部位置为（0.24，−0.23，−0.48），旋转为（−8，−18，12）度，缩放为1，应用于原有手持容器下的新显示实例。实际画面已检查：两种瓶体完整可见、位于中心右下侧、不遮住准星；格子内图标可辨认。姿态属于可调工程默认，不代表用户确认的最终美术姿态。见[咖啡因画面](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/held-caffeine.png)及[苯甲酸钠画面](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/held-sodium.png)。

实际运行发现并修正三处场景问题：

1. 原药放置架的整体盒体包住内部原药。已改为与两层板及背板一致的三个碰撞盒；原模型、根旋转、全部36槽位变换保留。两种原药各36次架外射线命中均通过，墙、层板及背板继续阻挡射线。见[逐槽射线记录](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/slot-rays.json)。
2. 主场景上架原高度1.2、下架0.72，下架上层原药与上架底板发生54处网格包围盒交叠。按计划只把上架高度改为1.3，下架及槽位不变。修改前[测量记录](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/shelf-clearance-before-data.json)与修改后[测量记录](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/shelf-clearance.json)保留；修改后302项检查全部通过。
3. 仓库货架也使用整体盒体，遮住货架内的两种原药组。真实射线从（0.3，−1.4，−6.1）发出，先在（0.3，−1.820001，−6.800001）命中货架；资源路径、运行变换及形状尺寸见[定位日志](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/main-scene-collider-trace.stdout.log)。已将[仓库架碰撞](/D:/autolysis/main-autolysis/scenes/prefabs/prefab_furnitures/store_shelf_warehouse_0.tscn)拆成对应实际模型的四立柱、四层板，未移动物体或绕过首个命中规则。修正后，从架外能够取得两种原药。

主场景联调使用真实场景、玩家、中心射线、鼠标按钮事件和滚轮事件；为避免导航路径影响验收，测试脚本定点放置玩家。此项验证的是交互链与真实遮挡，不冒充人工走完整张地图。见[主场景画面](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统p1实施证据/checks/main-scene-group.png)。

## 连续原生报错的处理记录

用户截图显示的是操作系统原生内存读取错误。最初受限启动中出现引擎用户目录访问失败，两次测试进程以访问冲突退出；当时尚未修改道具运行脚本。随后在正常访问引擎用户目录的执行环境中重跑相同基线检查，均正常退出。

后续验证统一使用[单项检查入口](/D:/autolysis/main-autolysis/systems/item-system/tests/run_item_check.ps1)，单项错误立即停止后续执行；有超时限制，只终止本次启动的进程。当前最终验证均正常退出，未再次复现同类原生崩溃。没有取得崩溃转储，因此不能把底层崩溃原因断言为某个脚本或已确认的引擎缺陷。
