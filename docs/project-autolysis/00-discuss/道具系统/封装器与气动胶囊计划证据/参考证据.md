## 四 计划公式核验

实际使用脚本枚举并保存[规则核验数据](D:/autolysis/docs/project-autolysis/00-discuss/道具系统/封装器与气动胶囊计划证据/规则核验.json)。此数据为计划逻辑检查，不是现有或新增功能的运行结果。

| 核验 | 实际计算与结果 |
| --- | --- |
| 输入配对 | 罐状态为缺罐、空罐、满罐；胶囊状态为缺胶囊、空胶囊、封装胶囊。共3×3＝9组，恰好1组为满罐＋空胶囊。 |
| 开关互斥与取消 | 原选择为未选、零、一、二；点击开关为零、一、二。共4×3＝12组。同一类型再次点击得到未选，其他点击得到所点类型；所有结果选中数量均为0或1。 |
| 启动许可 | 在配置有效、稳定聚焦、无待取产物前提下，枚举罐3态×胶囊3态×选择4态×门4态×运行2态×开关运动2态×取放事务2态，共1152组。只有输入正确、选择有效、门静止且三个忙碌标志为否的6组允许启动，对应3种类型×门的2种静止状态。 |
| 完成后先取罐 | 完成、取空罐、补满罐、本轮产物取走、补空胶囊共5步：前3步保持选择，取产物清除选择；补空胶囊后恢复可选择。 |
| 完成后先取胶囊 | 完成、取产物、补空胶囊、取空罐、补满罐共5步：取产物立即清除选择；仅补空胶囊仍不能准备，补满罐后恢复可选择。 |

采用的许可公式为：输入组合正确，且已选择三种有效类型之一，且舱门处于完全打开或完全关闭，且没有运行、开关运动、取放事务。类型切换公式为：所点索引等于当前索引时清除选择，否则选择所点索引。完成保留由本轮产物是否成功取走决定，与罐槽是否为空分开。

上述计数由实际枚举断言校验：正确输入配对数量必须为1，允许启动数量必须为6，类型选择不得超过1；两条取物记录额外检查先取罐不复位、补满罐不恢复改选、取产物复位及空罐不能准备。全部断言通过。
