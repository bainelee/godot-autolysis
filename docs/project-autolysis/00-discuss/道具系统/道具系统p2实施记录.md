## 二、几何实测与保护结果

原药架整体盒尺寸为（1.1999999，0.57，0.4），局部中心为（4.212009×10⁻⁸，0.285，−0.2）。仓库架整体盒尺寸为（2.2，2.2，0.59999996），局部中心为（1.1920929×10⁻⁷，1.1，0.3）。

实际加载主场景后，药瓶碰撞联合局部范围约为（−0.57，0.04，−0.35）至（0.58，0.56，−0.09）。已逐一验证两种原药在上下架全部36槽的碰撞均在整体盒内，并测量两类架体全部网格，未发现覆盖不足。

上下架盒体世界高度范围分别约为1.30至1.87、0.72至1.29；实际间隙约0.01。高度1.285命中下架，1.305和原重叠区1.310命中上架；1.295穿过间隙后命中后方普通墙体，未误选架体。两架盒内起点分别命中所属架体。详见[几何与分层数据](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统第二部分实施证据/20260925-implementation/checks/shelf-layer-details.json)。

真实图形运行中，玩家物理处理保持启用。向原药架持续行走后停在纵坐标约−1.291961，向仓库架持续行走后停在约−1.084065，两次均记录到对应架体接触。第四层台阶实际跨越成功，头顶实体阻止起身，脚步和投放查询实际命中新层实体。[移动与接触数据](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统第二部分实施证据/20260925-implementation/checks/shelf-physics.json)。

实施前保存126份工程配置、脚本、场景和资源快照，以及原有工作区状态。逐文件摘要和架体分段比较确认：主场景、原药定义与显示资源、道具事务脚本、界面保持一致；架体非碰撞内容、36槽、模型、材质和主碰撞节点标识保持一致。主场景上下架位置未调整。详见[保护核对报告](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统第二部分实施证据/20260925-implementation/preservation.json)及[可重复核对脚本](/D:/autolysis/docs/project-autolysis/00-discuss/道具系统/道具系统第二部分实施证据/20260925-implementation/verify-preservation.ps1)。
